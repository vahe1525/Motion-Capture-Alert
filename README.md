# 🖥️ Motion Capture Alert

**Motion Capture Alert** ծրագիրը նախատեսված է շարժման հայտնաբերման և օգտատիրոջ ծանուցման համար, երբ համակարգչին միացված տեսախցիկի կադրերում փոփոխություն է նկատվում։  

Ծրագիրը համատեղում է **C++** և **C#** լեզուները՝ ապահովելով բարձր արդյունավետություն կադրերի մշակման և հաղորդակցություն օգտատիրոջ հետ։

---

## ⚙️ Հիմնական գաղափարը

- Տեսախցիկը մշտապես արձանագրում է կադրեր՝ օգտագործելով պրոյեկտի մեջ արդեն ներառված բոլոր ֆայլերը։  
- Յուրաքանչյուր նոր կադրը համեմատվում է նախորդների հետ։  
- Եթե փոփոխություն է հայտնաբերվում մի քանի հաջորդական համեմատությունների արդյունքում՝  
  - Կադրերը պահվում են համակարգչում։  
  - Օգտատիրոջ էլ. փոստին ուղարկվում է ծանուցում։  

> **Նշում:** Տեսախցիկի հետ աշխատանքի համար լրացուցիչ ֆայլեր ներբեռնելու անհրաժեշտություն չկա, բոլորը ընդգրկված են պրոեկտի մեջ։  

---

## 🧩 Կառուցվածքը

| Մաս | Նկարագրություն |
|------|----------------|
| **C++ մոդուլ** | Պատասխանատու է տեսախցիկից կադրերի ընթերցման, RGB մատրիցաների ձևավորման և կադրերի միջև տարբերության հաշվարկի համար։ |
| **C# մոդուլ** | Ստանում է տվյալներ C++ հատվածից և իրականացնում էլ. փոստի ուղարկումը օգտատիրոջ հասցեին։ |
| **Linux գրադարաններ** | Կադրերի ընթերցման և մշակման համար։ |
| **Սեփական ալգորիթմներ** | Կադրերի համեմատությունն ու տարբերության հաշվարկը իրականացվում է սեփական մշակած ալգորիթմներով՝ առանց արտաքին գրադարանների։ |

## 🧠 Հիմնական ֆունկցիոնալություն

- Շարժման հայտնաբերում իրական ժամանակում  
- Կադրերի խելացի համեմատություն՝ կեղծ ազդանշանները բացառելու համար  
- Պահպանված կադրերի ավտոմատ գրանցում համակարգչում  
- Ծանուցում էլ. փոստով շարժման դեպքում  

---

## 🛠️ Տեղադրում և գործարկում

1. Համակարգչին միացրեք տեսախցիկը։                        
2. Բացեք պրոյեկտը Linux միջավայրում։  
3. Վերահսկեք, որ C++ և C# կոմպիլյատորները տեղադրված են համակարգում։  
4. Կատարեք build՝ օգտագործելով **makefile**. Հրամանը՝

```bash

# Build և գործարկում
make
./motion_capture_alert

# Ծրագիրը սկսում է հետևել տեսախցիկին
# Եթե հայտնաբերվի շարժում՝
# - կադրերը պահպանվում են ./captured_frames/ ֆոլդերում
# - օգտատիրոջ էլ. փոստին ուղարկվում է ծանուցում
